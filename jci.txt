Step 2: Download and install ngrok
Why do we need ngrok?

Your Jenkins is running on your laptop using localhost:8080.

But GitHub's servers are on the internet. They cannot directly access your laptop's localhost.

ngrok solves this problem by creating a publicly accessible URL that forwards requests to your local Jenkins server.








charliee2000.github.io


2.1 Download ngrok
1. Open: ngrok official download page.
2. Sign up for a free account if required.
3. Download ngrok for Windows.
4. Extract the downloaded ZIP file.
5. Locate ngrok.exe.
You can extract it into a folder such as:
C:\ngrok\
    ngrok.exe


2.2 Open Command Prompt inside the ngrok folder
1. Open the folder containing ngrok.exe.
2. Click the address bar in File Explorer.
3. Type cmd.
4. Press Enter.
A Command Prompt will open in that directory.
2.3 Connect your ngrok account
1. Open ngrok Authtoken page.
2. Copy your authentication token.
3. In Command Prompt, execute:
ngrok config add-authtoken YOUR_AUTH_TOKEN


Replace YOUR_AUTH_TOKEN with the actual token you copied.

Example:
ngrok config add-authtoken 2abcxxxxxxxxxxxxxxxx


Expected result
You should see a message indicating that the authtoken was saved.

Security: Never share your ngrok authentication token with anyone.

Step 4: Configure GitHub Webhook
A webhook is a mechanism through which GitHub sends an HTTP request to another application when a particular event occurs.

In our experiment:
- Event: Push code to GitHub.
- Sender: GitHub.
- Receiver: Jenkins.
- Purpose: Automatically trigger a Jenkins build.
4.1 Open your GitHub repository
1. Open GitHub.
2. Log in.
3. Open the repository you want to connect to Jenkins.
4.2 Open Webhook settings
Navigate through:
Repository
   |
   v
Settings
   |
   v
Webhooks
   |
   v
Add webhook










cjh5414.github.io


4.3 Fill in the webhook details
You will see a form.

Fill it as follows:
Field	Value
Payload URL	Your ngrok URL + /github-webhook/
Content type	application/json
Secret	Leave empty
SSL verification	Enable
Events	Just the push event
Active	Checked

Example Payload URL:
https://example.ngrok-free.dev/github-webhook/


Be careful: Do not enter only the ngrok URL. You must append:
/github-webhook/


4.4 Save the webhook
Click:
Add webhook


GitHub will save the webhook and normally send an initial ping event.
Expected result
Your webhook should appear in the repository's webhook list.

11.2 Test Failed Build
Now deliberately create a build failure.

For a Freestyle job, one simple method is:
1. Open your Jenkins job.
2. Click Configure.
3. Find the Build section.
4. Add a temporary Execute Windows batch command build step.
5. Enter:
echo Testing build failure
exit /b 1


6. Save the job.
7. Click Build Now.
This command deliberately returns a non-zero exit code, causing the build to fail.
Important
Only use this temporary command for testing. Remove it after the test so your normal project can build successfully again.
11.3 Verify the failure email
