Step 4: Configure the first Maven build step – clean
1. Scroll down to Build Steps.
2. Click Add build step.
3. Select Invoke top-level Maven targets.
4. Configure:
Field	Value
Maven Version	MAVEN_HOME
Goals	clean

What does clean do?

It removes previously generated build files, usually from the target folder.

For example:
Before clean:

Project/
  src/
  target/
    old-build-files/

After clean:

Project/
  src/


This prevents old build output from interfering with the new build.
Step 5: Configure the second Maven build step – install
1. Click Add build step again.
2. Select Invoke top-level Maven targets.
3. Configure:
Field	Value
Maven Version	MAVEN_HOME
Goals	install

What does install do?

It:
- Compiles the Java source code.
- Runs the tests configured in the Maven project.
- Packages the application.
- Installs the generated artifact into the local Maven repository if the build succeeds.

Part C – Troubleshooting common errors
These are worth understanding because Jenkins experiments often fail due to configuration mistakes.
11. Common errors and their solutions
Error	Reason	What to do
mvn is not recognized	Maven not installed or not configured	Check Maven installation and Jenkins MAVEN_HOME
No such Maven installation	Tool name mismatch	Set the Maven version to MAVEN_HOME
Couldn't find any revision to build	Wrong Git URL or branch	Verify the repository URL and branch
BUILD FAILURE	Compilation or test error	Read Console Output and identify the first actual error
No artifacts found	Archive pattern or output path is wrong	Check the build job's archived files
No wars found	No WAR was generated or copied	Check target/*.war and the Copy Artifact configuration
Connection refused	Tomcat is not running or URL/port is wrong	Start Tomcat and verify port 8085
401 Unauthorized	Incorrect Tomcat credentials	Check username/password and roles
403 Forbidden	Tomcat Manager access restrictions	Check Manager access configuration
Deployment fails	WAR file or Tomcat configuration problem	Check the Deploy job's console output
